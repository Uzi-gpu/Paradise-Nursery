# Paradise Nursery Shopping Cart (e-plantShopping)

Paradise Nursery is an online plant shop shopping cart application built with React and Redux Toolkit.

This project is the final project for IBM's Developing Front-End Apps with React course on Coursera. It lets users browse houseplants, add them to a shopping cart, update quantities, and review the total cost before checkout.

## Live app
https://uzi-gpu.github.io/Paradise-Nursery/

## Project name

- Repository: `e-plantShopping`
- Application: Paradise Nursery

## Features

- Landing page with company details and a Get Started button
- Product listing page with houseplants grouped into categories
- Add to Cart with a disabled button after a plant is added
- Shopping cart with quantity controls, item totals, and delete
- Navbar with Home, Plants, and Cart links plus a live cart count
- Checkout button that shows a Coming Soon message

## How to run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

The app is hosted on GitHub Pages from this public repository.
